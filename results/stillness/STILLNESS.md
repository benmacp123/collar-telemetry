# How often living animals stay still

Generated by `make stillness`; do not edit by hand. A still bout is one of the mortality detector's own clusters (100 m box, at least 6 fixes), run with no window so nothing alerts. The final stationary period of a dead or ambiguous track is left out, as it may be a carcass, and so is everything after a tag event began, as it is not an animal resting. Each cell is *bouts longer than the column (per animal-month)*; animal-months run from first to last fix on every deployment, as in the evaluation's load. Vultures are the tuning set only: every tuning bird wears an Argos PTT tag and every solar GPS/GSM tag is in the held-out set, so tag types cannot be compared here.
